# Квиз «От стартапа к мировому бренду»

## Как опубликовать на GitHub Pages
1. Создайте публичный репозиторий, например `unicorn-quiz`.
2. Загрузите файл `index.html` в корень репозитория (другие файлы необязательны).
3. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Выберите `main` и `/ (root)`, нажмите **Save**.
5. После публикации откройте ссылку вида `https://USERNAME.github.io/unicorn-quiz/`.
6. Создайте QR-код на опубликованную ссылку и поместите его на 14-й слайд.

Квиз работает полностью в браузере, без сервера, регистрации и отправки ответов. Результаты каждого участника не собираются централизованно.
